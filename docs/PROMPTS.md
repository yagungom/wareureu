# ChatGPT 이미지 프롬프트 모음

## 1. 스테이지 배경 10종

### 사용법
1. ChatGPT에 아래 **공통 스타일** + **스테이지별 장면**을 이어 붙여서 요청합니다.
2. 받은 이미지를 아래 파일명으로 저장해 `assets/bg/` 폴더에 넣습니다. (png·jpg·webp 모두 가능)
3. 다시 배포하면 끝. 파일이 없는 스테이지는 코드로 그린 임시 배경이 나옵니다.

> 💡 ChatGPT 이미지는 장당 2~3MB라서 [squoosh.app](https://squoosh.app)에서 **webp, 가로 1920px**로 줄이면 로딩이 빨라져요 (장당 300KB 안팎).

### 공통 스타일 (매번 앞에 붙이기)

```
아이들 그림책 같은 밝고 귀여운 2D 일러스트 배경. 부드러운 파스텔 색감, 깔끔한 윤곽선.
가로로 긴 16:9 와이드 화면.
사람, 동물, 캐릭터, 글자, 로고는 절대 넣지 않기.
화면 가운데와 아래쪽은 단순하게 비워 두기 (실제 가족 사진이 그 자리에 합성됨).
하늘 쪽에는 작은 물체를 많이 그리지 않기 (위에서 떨어지는 게임 캐릭터와 헷갈리지 않게).
지평선은 화면 높이의 55~65% 위치.
```

## 2. (선택) 떨어지는 캐릭터를 ChatGPT 그림으로 바꾸기

기본 캐릭터는 코드로 그려져 있어 따로 안 만들어도 됩니다. 화풍을 배경과 맞추고 싶을 때만 쓰세요.

1. 아래 프롬프트에 캐릭터 이름만 바꿔서 요청 → **투명 배경 PNG**로 받기
2. `assets/characters/<id>.png` 로 저장 (id는 아래 표)
3. `js/config.js` 에서 `CUSTOM_CHARACTERS: true` 로 바꾸고 배포

```
귀여운 [캐릭터] 스티커 일러스트 1개. 정면을 보는 동글동글한 모양, 큰 눈과 발그레한 볼,
두꺼운 진한 외곽선, 밝은 색. 투명 배경 PNG, 정사각형, 그림자 없음, 글자 없음.
```

| 테마 | id (파일명) |
|---|---|
| 과일 | apple, strawberry, watermelon, banana, grape, peach, pineapple, tangerine |
| 바다 | fish, octopus, whale, crab, turtle, jellyfish |
| 동물 | rabbit, bear, polarbear, fox, arcticfox, pig, chick, penguin, panda, sheep |
| 탈것 | car, taxi, bus, firetruck, airplane, hotairballoon, train, rocket, ufo |
| 기타 | star, planet, heart, bomb (폭탄은 꼭 '귀여운 만화풍 폭탄'으로) |

> ⚠ 실제 만화·게임 캐릭터(포켓몬 등)를 닮게 만들지 마세요. 공개 서비스에서는 저작권 문제가 됩니다.
