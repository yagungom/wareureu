# ChatGPT 이미지 프롬프트 모음 (테마 25개)

100 스테이지 = **테마 25개 × 분위기 4가지**(낮 → 노을 → 밤 → 무지개 축제).
테마마다 **배경 1장 + 스티커 시트 1장**, 모두 50장이면 끝입니다. 노을·밤·축제 분위기는 게임이 배경 위에 색을 입혀 자동으로 만들어요.

| 스테이지 | 분위기 |
|---|---|
| 1~25 | ☀️ 낮 |
| 26~50 | 🌇 노을 |
| 51~75 | 🌙 밤 |
| 76~100 | 🌈 무지개 축제 |
| 101~ | 다시 1번부터 (무한) |

## 넣는 방법

1. ChatGPT에서 아래 프롬프트를 그대로 붙여 넣어 이미지를 만듭니다. (한 대화에서 이어서 만들면 그림체가 비슷하게 맞춰져요. 두 번째부터는 "앞과 같은 그림체로"를 덧붙이면 좋아요.)
2. 파일 이름을 맞춰 저장합니다.
   - 배경 → `assets/bg/<테마>.png` (png·jpg·webp 가능)
   - 스티커 시트 → `assets/items/<테마>.png` (**투명 배경 png**, 흰 배경도 자동으로 지워 봄)
3. 저장소에 올리면(또는 Claude 대화에 이미지를 보내면) 자동 적용. 없는 테마는 코드로 그린 임시 그림이 나옵니다.

- 스티커 시트는 **3칸 × 2줄**, 순서는 윗줄 왼쪽부터. 게임이 6개로 자동으로 잘라 씁니다. 순서가 틀려도 게임은 되지만 이름이 바뀌어요.
- (선택) 분위기별 배경을 따로 만들고 싶으면 `assets/bg/<테마>-sunset.png`, `-night.png`, `-special.png`.
- ⚠ 실제 만화·게임 캐릭터(포켓몬 등)를 닮게 만들지 마세요. 공개 서비스라 저작권 문제가 됩니다.
- ⚠ 흰 바탕에 빨간 십자(적십자 표장)는 그리지 마세요. 법으로 사용이 제한돼요. 구급차·약상자는 빨간 하트로 대신합니다.

### 공통: 배경

```
어린이 그림책 같은 밝고 귀여운 2D 일러스트 게임 배경을 그려줘.
- 부드러운 파스텔 색감, 깔끔한 윤곽선, 가로로 넓은 이미지(1536×1024)
- 사람·동물·캐릭터·글자·로고는 절대 넣지 않기
- 해와 달은 그리지 않기 (게임이 노을·밤 분위기를 따로 입힘)
- 화면 가운데와 아래쪽은 단순하게 비워 두기 (가족 모습이 그 자리에 합성됨)
- 하늘에 작은 물체를 많이 그리지 않기 (위에서 떨어지는 아이템과 헷갈리지 않게)
- 지평선은 화면 높이의 55~65% 위치, 위아래 끝은 조금 잘릴 수 있으니 중요한 건 넣지 않기
```

### 공통: 스티커 시트

```
어린이 게임용 귀여운 스티커 6개를 한 장에 그려줘.
- 배치: 가로 3칸 × 세로 2줄, 스티커끼리 넉넉히 떨어뜨려 서로 닿지 않게
- 스타일: 동글동글한 카와이 스타일, 큰 눈과 웃는 얼굴(물건도), 굵은 진한 갈색 윤곽선, 밝은 색, 두꺼운 흰색 스티커 테두리
- 배경: 투명 배경 PNG (안 되면 아주 깨끗한 흰색 단색)
- 글자·숫자·그림자·바닥·장식 없음, 6개 크기는 비슷하게
- 이미지 크기 1536×1024 가로
```
