🏆 랭킹

이렇게 놀아요

  1. 📱 폰 모드 카메라 없이 폰 화면에서 손가락으로 떨어지는 친구들을 터치해요. 가로든 세로든 폰 화면을 꽉 채워요. 폭탄은 누르면 안 돼요!
  2. 📺 TV에 연결 (카메라 모드) 유선 또는 스마트뷰로 미러링해요. 스마트뷰는 화면 비율 → 연결된 기기에서 전체 화면을 고르면 꽉 차요.
  3. 📱 폰 세우기 폰을 가로로 세워 가족을 향하게 두고, 2~3걸음 뒤로 서요. 몇 명이든 같이 할 수 있어요. 카메라는 시작 화면이나 대기실의 "카메라 바꾸기"에서 골라요.
  4. 🙌 잡기 화면에 노란 동그라미로 보이는 게 내 손이에요. 손으로 떨어지는 친구들을 잡거나 건드리면 점수!
  5. 💣 피하기 손으로 폭탄을 건드리면 생명이 하나 날아가요. 생명 5개가 다 없어지면 끝. 가끔 떨어지는 하트는 생명 +1!
  6. 😢 놓치면 친구가 바닥까지 떨어지면 −10점(아기 모드 −5점). 놓침 칸이 다 차면(5마리, 아기 모드 8마리) 생명 −1. 처음 5초(아기 모드 10초)는 봐줘요.
  7. 🗺️ 스테이지 한 스테이지는 100초. 테마 25개(해변 → 바닷속 → 농장 …)가 낮 → 노을 → 밤 → 무지개 축제로 바뀌며 100스테이지까지 이어져요. 스테이지마다 떨어지는 친구들도 달라지고, 20초마다 빨라져요. 사이사이 3초 쉬어요. 시작 테마는 매판 랜덤이고, 대기실의 🎨 버튼으로 고를 수도 있어요.
  8. 🏆 점수 친구 1마리 10점(연속으로 잡으면 최대 20점) − 놓친 감점 + 버틴 1초마다 3점 + 스테이지 클리어 보너스(스테이지 번호 × 100점). 0점 아래로는 안 내려가요.
