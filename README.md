# 와르르 캐치! 🍉🐥🚗💣

카메라로 가족을 인식해서 배경을 바꾸고(크로마키), 하늘에서 떨어지는 친구들을 몸으로 잡는 가족용 웹 게임.
설치 없이 **크롬(웹/모바일 웹)** 에서 돌아가고, 폰을 **TV에 미러링**해서 큰 화면으로 즐기는 걸 기본으로 만들었습니다.

- 빌드 도구 없음: 정적 파일 그대로 배포 (HTML + JS 모듈)
- 사람 인식: MediaPipe (기기 안에서 처리, 영상 전송 없음) — 엔진·모델을 이 폴더에 같이 넣어 외부 서버 호출 없음
  - 자세 인식으로 **손 위치**를 찾아 **손으로만** 잡기 판정 (2~4m 떨어져도 인식)
  - 사람 분리 + 자세 인식 영역으로 배경 합성 (가까이·멀리 모두)
  - 인식은 별도 처리(Web Worker)에서 돌려 게임 화면은 60fps로 부드럽게
  - 카메라 바로 앞(약 1m 이내)에 붙은 사람은 반투명 + "한 걸음 뒤로!" 말풍선
- 최대 6명까지 동시에, 점수는 한 팀으로 합산
- 한 판 = 100초 스테이지가 계속 이어짐. **100 스테이지 = 테마 25개 × 분위기 4가지**(낮 → 노을 → 밤 → 무지개 축제), 101부터 다시 1번 (무한). 스테이지마다 배경과 떨어지는 친구 6종이 테마에 맞게 바뀜
- 플레이 방식 2종: 📺 카메라 모드(손으로 잡기, TV 미러링 추천, 16:9 고정) / 📱 폰 모드(카메라 없이 손가락 터치, **가로·세로 모두 폰 화면을 꽉 채움** — 폴드 펼친 화면 포함)
- 난이도 2종: 일반 / 🍼 아기 모드(느리고 폭탄 적음, 랭킹 따로)
- 랭킹: 통합 랭킹 × 모드 × 오늘/이번 주/이번 달, 온라인 전체 + 우리 기기 기록, **이번 판이 상위 몇 %인지** + 점수 분포(기록이 20개 미만이면 점 그래프) + TOP 10(도달 스테이지 표시)

## 1. 배포 (Vercel, 약 5분)

카메라는 **https 주소에서만** 켜지므로 배포가 필요합니다.

1. 이 폴더를 GitHub 저장소에 올립니다.
2. [vercel.com](https://vercel.com) → **Add New → Project** → 저장소 선택 → Framework: **Other** → Deploy
   - Build Command·Output 설정 필요 없음 (정적 사이트)
3. 받은 `https://xxx.vercel.app` 주소를 갤럭시 크롬으로 열면 끝.
4. 크롬 메뉴 → **홈 화면에 추가** 하면 주소창 없는 전체화면 가로 앱처럼 실행됩니다.

> Netlify·Cloudflare Pages도 됩니다 (`_headers` 파일이 보안 헤더를 적용). GitHub Pages는 보안 헤더를 못 붙여서 비추천.

**PC에서 먼저 확인:** 폴더에서 `npx serve .` → `http://localhost:3000` (localhost는 https 아니어도 카메라 허용). 카메라 없이 보려면 주소 뒤에 `?touch=1`.

## 2. 온라인 랭킹 켜기 (Supabase 무료)

설정 안 하면 "우리 기기 기록"만 동작합니다.

1. [supabase.com](https://supabase.com) → New project (Region: **Northeast Asia (Seoul)**)
2. 왼쪽 **SQL Editor** → `supabase/schema.sql` 전체 붙여넣기 → **Run**
3. 대시보드 상단 **Connect** 버튼(또는 Project Settings → API Keys)에서 **Project URL** 과 **publishable(anon) 키** 복사
4. `js/config.js` 에 입력 후 다시 배포
   ```js
   SUPABASE_URL: 'https://abcd1234.supabase.co',
   SUPABASE_KEY: 'sb_publishable_xxxxxxxx',
   ```
5. 게임 → ⚙️ 설정 → "온라인 랭킹: 켜짐 ✅" 확인

> ⚠️ **service_role / secret 키는 절대 넣지 마세요.** publishable 키는 원래 공개용이고, 보안은 서버 함수가 담당합니다.

## 3. 배경·아이템 이미지 (ChatGPT)

`docs/PROMPTS.md` 의 프롬프트로 **테마마다 2장**(배경 1장 + 스티커 시트 1장), 모두 50장을 만듭니다.

| 종류 | 파일 | 설명 |
|---|---|---|
| 배경 | `assets/bg/<테마>.webp` (png·jpg도 가능) | 낮 그림 1장. 노을·밤·축제는 게임이 색을 입혀 자동으로 만듦. 따로 만들고 싶으면 `<테마>-sunset.png` / `-night.png` / `-special.png` |
| 스티커 | `assets/items/<테마>/<0~5>.webp` | 미리 잘라 둔 아이템 6개 (가볍고 폰에서 자르는 시간이 없음) |
| 스티커 시트 | `assets/items/<테마>.png` | 아이템 6개를 3칸 × 2줄로. 위의 잘라 둔 그림이 없으면 게임이 직접 잘라 씀 (투명 배경 권장, 흰 배경도 자동으로 지워 봄) |

현재 25개 테마 50장 모두 들어가 있음 (2026-11-02, Codex의 내장 이미지 생성으로 제작). 원본 png 는 git 기록에 남아 있고, 저장소에는 배경 webp(장당 약 110KB)와 잘라 둔 스티커 webp(개당 약 20KB)만 둠.

없는 테마는 코드로 그린 임시 배경과 이모지·손그림 스티커가 나옵니다. 테마 키: `beach sea farm city orchard forest bugs dessert dino sky jungle veggie snow toys sports music pets kitchen harbor construction garden park castle party space`

## 4. TV로 하기

| 방법 | 설명 |
|---|---|
| **유선 미러링** (추천) | USB-C → HDMI 어댑터로 연결. 지연이 거의 없음 |
| **무선 미러링** (스마트뷰) | 화면이 살짝 늦게 보이지만 판정은 폰에서 실시간이라 정확함. **스마트뷰 아이콘 → 화면 비율 변경 → '연결된 기기에서 전체 화면'** 을 꼭 선택 (특히 폴드) |

- 시작 화면에서 **📷 후면 / 🤳 전면** 카메라를 고르고, 대기실의 **카메라 바꾸기**에서 광각 등 원하는 렌즈를 미리보기 보면서 고를 수 있어요 (선택은 저장됨)
- 폰을 가로로 세워 가족 쪽을 보게 두고 **2~3걸음 뒤**에 서기. 몸 전체가 나오면 가장 좋음
- 게임 화면은 항상 **16:9** 로 그려서 TV에 꽉 찹니다 (폴드 펼친 화면에선 위아래 여백)
- 대기실에서 노란 풍선을 손으로 1초 터치 → 시작. 끝나면 오른쪽 위 "다시!" 풍선을 터치 → 바로 다음 판 (폰 안 만지고 계속 가능)
- 스테이지 2부터는 몇 분씩 이어지므로 폰은 충전기에 꽂아 두세요 (게임 중 화면 꺼짐은 자동 방지)

### 전체화면 버튼 (⛶)

시작 화면 오른쪽 위, 게임 중 오른쪽 아래에 있습니다. 브라우저마다 자동으로 맞춰 동작해요. PC에서는 키보드 **F** 로도 켜고 끌 수 있습니다.

| 환경 | 동작 |
|---|---|
| 안드로이드 크롬·삼성 인터넷 | 버튼 → 전체화면 + 가로 고정 |
| PC 크롬·엣지·파이어폭스 | 버튼 → 전체화면 (브라우저 단축키는 F11) |
| 맥 사파리 | 버튼 → 전체화면 (사파리는 F11 대신 ⌃⌘F) |
| 아이패드 사파리 | 버튼 → 전체화면 |
| 아이폰 사파리·크롬 | 애플 정책상 웹 전체화면이 안 됨 → 버튼을 누르면 "공유 → 홈 화면에 추가" 안내. 홈 화면 아이콘으로 열면 주소창 없이 꽉 참 (이때 버튼은 자동으로 숨김) |

## 5. 게임 규칙

| 항목 | 내용 |
|---|---|
| 스테이지 | 1개 = **100초**. 테마 25개가 고정 순서로 나오고, 1~25 낮 · 26~50 노을 · 51~75 밤 · 76~100 무지개 축제. 100 다음은 1번부터 다시 (무한) |
| 속도 | **20초마다 레벨 +1** → 스테이지 N 은 **Lv.N 에서 시작해 Lv.N+4 로 끝** (스테이지 1: Lv.1~5, 스테이지 2: Lv.2~6 …). 레벨이 오를수록 빨라지고 자주 떨어지고 폭탄 비율이 늘어남 (상한 있음) |
| 휴식 | 스테이지 사이 **3초**: 클리어 축하 → 다음 스테이지 소개. 이때는 아무것도 안 떨어짐 |
| 잡기 | 카메라 모드: **손으로만** 판정, 화면의 노란 동그라미가 인식된 손 (몸·머리에 닿는 건 무시) · 폰 모드: 손가락으로 터치(여러 손가락 가능, 쓸어도 됨) |
| 랭킹 | 📺 카메라 / 📱 폰 × 일반 / 아기 모드로 따로 집계 (온라인 전체 + 이 기기 기록 모두) |
| 점수 | 캐릭터 1개 **10점**, 2.5초 안에 또 잡으면 콤보 +1점씩 최대 **20점**. 2.5초 지나면 콤보 사라짐 |
| 시간 점수 | 버틴 1초마다 **3점** (휴식·일시정지 시간 제외) |
| 클리어 보너스 | 스테이지 N 을 끝까지 버티면 **N × 100점** (1→100, 2→200, 3→300 …) |
| 생명 | 최대 **5개**. 폭탄에 닿으면 −1, 친구를 일정 수 놓쳐도 −1, 가끔 떨어지는 하트는 +1. 0이 되면 끝 |
| 놓치기 | 친구가 바닥까지 떨어지면 **−10점**(아기 모드 −5점, 그때 점수보다 많이 깎지는 않음) + 콤보 끊김. 놓침 칸이 다 차면(**5마리**, 아기 모드 **8마리**) 생명 −1. 처음 5초(아기 10초)는 봐줌. 가만히 서서 시간 점수만 쌓는 꼼수 방지 |
| 아기 모드 | 속도 약 70%, 폭탄 절반, 캐릭터 조금 더 크게, 하트 자주. 랭킹 따로 |
| 배려 | 처음 5초(아기 모드 10초)는 폭탄 없음. 화면에 사람이 4초간 없으면 자동 일시정지 |
| 캐릭터 | 사람이 있는 쪽으로 더 자주 떨어짐 (구석에 숨어 피하기 방지) |
| 폭탄 | 손으로 건드리면 생명 −1 (몸에 떨어지는 건 괜찮음) |

점수 = 잡은 점수 − 놓친 감점 + 버틴 초 × 3 + 클리어 보너스 합계 (0점 아래로는 안 내려감).
규칙 숫자를 바꾸려면 `js/config.js` 의 `RULES` 와 `supabase/schema.sql` 의 `submit_score` 검증을 **같이** 바꿔야 합니다 (서버가 같은 공식으로 점수를 다시 계산해서 비교).

## 6. 보안·개인정보

| 위험 | 대응 |
|---|---|
| 카메라 영상 유출 | 영상은 폰 메모리 안에서만 처리. 저장·전송 코드 없음. 게임 밖 화면에선 카메라를 바로 끔 |
| 외부 스크립트 변조·추적 | 엔진·모델·코드 전부 자체 호스팅. CSP로 외부 스크립트 차단, 서버 통신은 Supabase만 허용 (MediaPipe 내장 사용통계 전송도 차단됨) |
| 개인정보 수집 | 로그인·이메일·연락처 없음. 서버엔 팀 이름·점수·시간·스테이지만 저장 (도배 방지용 IP 해시는 2일 뒤 삭제, 화면 설정에도 안내) |
| 아이 실명·전화번호 | "실명 대신 별명" 안내, 숫자 7자리 이상 금지 |
| 욕설·사칭 팀 이름 | 클라이언트 + 서버 이중 필터 (관리자·운영자 사칭 포함), 관리자가 숨김 처리 가능 |
| XSS | 사용자 입력은 textContent 로만 출력, 팀 이름은 한글·영문·숫자·일부 기호만 허용, CSP |
| DB 직접 조작 | 테이블은 비공개 스키마 + RLS + 권한 회수. 브라우저는 함수 3개만 호출 가능 |
| 점수 조작 | 서버 발급 1회용 세션, 서버 시계로 플레이 시간 검증, 점수 공식·초당 최대치 검사, 실패해도 세션 소멸 |
| 도배·과부하 | IP 기준 분당 12판·시간당 240판 제한. IP는 날짜별 솔트 해시로만, 2일 뒤 삭제 |
| 클릭재킹·기타 | frame-ancestors none, X-Frame-Options, nosniff, no-referrer, HSTS, 카메라 외 권한 차단 |

> 솔직한 한계: 브라우저 게임은 코드가 사용자 기기에서 돌기 때문에 점수 조작을 100% 막을 수는 없습니다. 위 장치로 "상식 밖 점수"는 서버가 거부하고, 남는 건 관리자가 숨기면 됩니다.

## 7. 설정 화면

카메라 선택, 거울 모드(좌우 반전), 효과음/배경음악, 인식 화질(최고/고화질/표준/절전), 성능 정보 표시, 이 기기 기록 지우기.
- **성능 정보 표시**를 켜면 화면 위에 카메라 fps·인식 시간·인식된 사람/손 수가 나와요.
- 손 인식이 둔하면 **최고**(정확한 모델), 화면이 끊기거나 폰이 뜨거우면 **표준/절전**으로 바꿔 보세요.

## 9. 알아두면 좋은 점

- 실내가 너무 어둡거나 사람 뒤가 복잡하면 인식이 거칠어집니다. 밝은 곳, 단순한 벽 앞이 좋아요.
- 여러 명이 겹쳐 서면 한 덩어리로 인식됩니다 (협동 점수라 게임엔 문제 없음).
- 처음 실행할 때 인식 엔진(약 4MB 압축)을 받느라 몇 초 걸리고, 이후엔 캐시됩니다.
- 라이선스: MediaPipe 엔진·모델은 Apache-2.0. 출처는 `vendor/mediapipe/NOTICE.txt`·`models/NOTICE.txt`, 라이선스 전문은 같은 폴더의 `LICENSE.txt`.
